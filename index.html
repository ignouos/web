04 / YOUR TURN

Your first contribution
starts right here.

You don’t need to be an expert. Clear documentation, a thoughtful issue, or a small fix can make a project better for everyone.

Find a project ↗
Browse organization issues ↗Suggest a website improvement ↗
01

Find a project

Read its README and look for an issue that matches your interests.

02

Fork and clone

Fork the repository on GitHub, then clone your fork to your computer.

git clone <your-fork-url>
03

Make a focused change

Create a branch, make one useful improvement, and check your work.

git switch -c fix/clear-description
04

Open a pull request

Push your branch and explain what changed and why. Be open to feedback.
